# 기획 요약

## 컨셉

사려는 금액을 입력하면 가정 이율과 과거 수익률로 환산해 3D 연출과 함께 보여 주는 충동 소비 억제 웹앱.
재미 목적의 시뮬레이션이며 특정 상품을 소개하지 않는다.

- 타깃: 배달과 카페 지출이 잦은 2030
- 흐름: 항목과 금액 입력, 환산 결과와 한마디, 참았어요 또는 먹었어요, 누적 기록
- 분류: 게임이 아닌 생활과 금융 성격

## 환산 방식

| 방식 | 입력 | 출력 |
| --- | --- | --- |
| 예금형 | 금액, 가정 연 이율 | 1년 뒤 예상 금액과 적용 이율 |
| 적금형 | 금액, 가정 연 이율, 기간 | N년 뒤 예상 금액과 적용 이율 |
| ETF 타임머신형 | 금액, ETF 유형(기술주, 대형주 등), 넣었다면 보고 싶은 연도 | 그때 넣었다면 현재 금액과 유형 상승률 |

화면에는 예금과 적금은 이율만, 주식은 ETF 유형의 상승률만 표시한다. 상품 설명과 기관 정보는 보여 주지 않는다.

## 재미 요소

- 유혹 재판: 변론 카테고리를 고르면 판사 캐릭터가 판결문을 읽는다.
- 평행우주 영수증: 같은 금액이 다른 우주에서 무엇이 됐는지 일상 단위로 환산한다.
- 미래의 내가 보낸 한 줄: 10년 뒤 사용자가 보낸 짧은 편지 형식.
- 고민 시간 환산: 결과 화면에 머문 시간을 시급으로 빗댄 한마디.
- 3D 저금통, 3D 저울, 타로 카드 플립. 모두 연출용이며 조작과 보상이 없다.
- 재물운 타로: 하루 한 장, 소비 조언 한 줄. 환산 판정과 무관.

## 가드레일

- 상품명, 상호명, 브랜드명, 종목명, 티커 금지. 유형명만 사용.
- 사용자 직접 입력도 상호명과 브랜드명을 거부하고 일반 명칭만 허용. 입력 원문은 표시와 저장과 전송을 하지 않음.
- 예금과 적금은 이율만, 주식은 ETF 유형 상승률만 표시.
- 명령형 권유 금지. 가정법과 관찰형만 사용.
- 결과 화면 고정 문구 표시.
- 레벨, 경험치, 캐릭터 육성, 확률형 뽑기, 현금성 보상 금지.
- 앱인토스 가이드라인과 금융 관련 규정은 출시 전 직접 확인.

## 지원서 문장 (완성 후 사실 확인하고 사용)

- 충동 소비 억제 웹앱을 기획부터 3D 연출, 테스트 자동화까지 단독 구현
- 런타임 LLM 호출 대신 문구를 사전 생성하고 계산은 규칙 기반으로 분리해 비용과 지연과 환각 위험을 구조적으로 차단
- 금칙어 스캔과 문구 스키마 검증과 E2E를 GitHub Actions에 연결해 금융 문구 규제 리스크를 자동 점검
- 상품명 없이 이율과 ETF 유형 상승률만 쓰고 사용자 입력의 상호명도 필터링하는 정책으로 금융 서비스 컴플라이언스를 고려한 설계 경험
