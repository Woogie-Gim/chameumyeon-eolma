### 글자 수 점검

글자 수는 코드 포인트 기준으로 센다. 콘솔이 공백을 세는지는 가이드에 없어 두 값을 함께 적는다. 결과는 공백 포함 기준이다. 상세 설명은 가이드(console-workspace)에 글자 수 제한이 없어 미확인으로 둔다.

### 상세 설명

```text
사고 싶은 물건이나 먹고 싶은 메뉴의 금액을 입력하고 품목을 고르면 참았을 때 예금형·적금형 이율 기준으로 몇 년 뒤 얼마가 되는지 보여 줘요. 결과 화면에서는 3D 저금통과 저울 연출로 불어난 금액을 확인하고 기간 슬라이더로 기간을 바꿔 볼 수 있어요. 기술주·대형주 ETF형 상승률로 과거에 참았다면 지금 얼마인지도 재미로 볼 수 있어요. 타로 탭에서는 뒷면으로 펼쳐진 카드 5장 중 한 장을 골라 오늘의 재물운 한마디를 확인해요. 모든 결과는 재미로 보는 단순 계산이며 투자 권유나 상품 추천이 아니에요. 입력한 내용은 서버로 전송되지 않고 기록은 이 기기에만 저장돼요.
```

### 출시 노트 (초안)

```text
첫 출시예요. 사려던 금액을 가정 이율과 과거 지수 상승률로 환산해 3D 저금통과 저울로 보여 줘요. 참은 기록과 오늘의 재물운 타로도 함께 볼 수 있어요.
```

### 메모 (심사 담당자용, 초안)

```text
로그인과 서버 없이 바로 쓸 수 있어요. 입력 화면에서 품목(예: 치킨)과 금액을 넣고 환산하기를 누르면 결과가 나와요. 다음, 참았어요 순서로 누르면 기록 화면에 쌓여요. 주요 기능 주소는 intoss://chameumyeon-eolma/tarot(타로), intoss://chameumyeon-eolma/record(기록)예요. 기록은 기기 저장소에만 있고 외부로 보내지 않아요. 모든 결과는 가정 시뮬레이션이며 금융 상품을 소개하거나 권유하지 않아요.
```

참고용 사실(현재 구현 기준, 요건 판단은 아님):

- 서버가 없고 외부로 전송하는 데이터가 없다. 런타임 외부 API 호출도 없다.
- 기기의 localStorage에만 저장한다.
  - `chameum.records.v1`: 날짜, 품목 id, 금액, 선택(참았어요 또는 샀어요/먹었어요)
  - `chameum.settings.v1`: 예금형 이율, 적금형 이율, 저사양 3D 끄기
- 사용자가 직접 입력한 문장 원문은 저장하거나 표시하거나 전송하지 않는다. 사전에 있는 일반 품목 id만 저장한다.
- 설정의 데이터 초기화로 모든 저장값을 지울 수 있다.
- 앱 안의 이용 안내 화면에 위 내용을 적어 두었다(`src/core/copy.ts`).
