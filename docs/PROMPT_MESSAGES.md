# 멘트 사전 생성 프롬프트 (로컬 LLM용)

개발 PC에서 한 번만 돌려 `src/data/messages.json`과 `tarot.json`을 채운다. 런타임에는 사용하지 않는다.

## 사용 순서

1. 카테고리(hunger, stress, reward, impulse) x 금액 구간(low, mid, high) x 톤(funny, calm, stern) 조합마다 아래 프롬프트를 실행한다.
2. 출력 JSON을 합쳐 `messages.json`으로 저장한다.
3. `npm run scan:banned`와 스키마 검증을 통과시킨다.
4. 무작위 30개는 직접 읽어 품질을 확인한다.

## 1. 소비 억제 멘트

```text
너는 충동 소비를 재치 있게 말려 주는 한국어 카피라이터다.
아래 조건에 맞는 문구 20개를 JSON 배열로만 출력한다.

조건:
- 카테고리: {category}
- 금액 구간: {band}
- 톤: {tone}
- 각 항목 형식: {"template": "..."}
- 숫자는 직접 쓰지 말고 {item}, {amount}, {years}, {future} 자리표시자만 사용
- {item}에는 치킨, 커피 같은 일반 품목명만 들어간다. 상호명과 브랜드명은 문구에 쓰지 않는다
- 상품명, 종목명, 금융기관명 금지
- 명령형 권유 금지: 사세요, 넣으세요, 투자하세요 등
- 가정법이나 관찰형 문장만 사용
- 한 문장 60자 이내
- 비난이나 수치심을 주는 표현 금지
- 이모지 금지
- JSON 외 다른 텍스트 출력 금지
```

## 2. 재물운 타로 카드 문구

```text
너는 재미로 보는 소비 운세를 쓰는 한국어 카피라이터다.
타로 메이저 아르카나 22장을 재물운 콘셉트로 재해석해 JSON 배열로만 출력한다.

조건:
- 각 항목 형식: {"id": 0, "name": "카드 이름", "keyword": "키워드", "adviceTemplate": "오늘의 소비 조언 한 줄"}
- 카드 이름은 원작 이름을 그대로 쓰지 말고 재물운 콘셉트로 새로 짓는다
- 숫자는 직접 쓰지 말고 {amount} 자리표시자만 사용 가능
- 상품명, 종목명, 금융기관명 금지
- 명령형 권유 금지. 관찰형과 가정형만 사용
- 한 문장 60자 이내
- 오락용이므로 단정적인 예언 표현 금지
- 이모지 금지
- JSON 외 다른 텍스트 출력 금지
```
